# fish-skill

A collection of reusable AI coding-agent skills.

## Install a skill from the npm package

```bash
npx fish-skill list
npx fish-skill install resume-copilot
```

By default skills are copied to `.agents/skills/`. Use `--target` to choose another agent skill directory.

## Repository layout

```text
skills/<skill-name>/SKILL.md
```

See `README.zh.md` for the full documentation.
