标题

我把“简历要有依据”做成了一个开源 Skill

正文

写项目经历时，我最在意一个问题：简历上的每句话，能不能说清它来自哪里。

所以做了 resume-copilot，一个用于整理经历、生成简历和准备面试的 Coding Agent Skill。

它先把材料整理成 Fact，再归入项目 Experience，形成有依据的 Claim，最后根据目标岗位生成 Resume View。仓库能证明“项目有这个功能”，个人贡献还需要单独确认；数字也要记录来源，不会为了好看凭空补指标。

以 fish-skill 为例：代码证明 CLI 提供 list/check/install；本人贡献确认后，简历才写“独立开发 Node.js CLI”。“78 项检查”则能回到 npm test 的结果。

简历可以生成 HTML 预览，提供 5 套主题，并通过浏览器打印成 PDF。面试准备则从简历里的项目描述继续追问：默认只输出问题；明确要求时，再按“直接回答＋展开说明”附参考答案。

适合想把个人项目、技术工作讲得更清楚的开发者。项目开源：GitHub 搜索 wjywy/fish-skill，进入 resume-copilot 目录即可查看。
